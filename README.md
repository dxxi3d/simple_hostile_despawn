Fixes mob-lag caused by picked-up items while safely dropping loot when mobs despawn.

* Allows hostile mobs holding picked-up loot to despawn naturally when away from players.
* Safely drops preserved equipment and inventory items (e.g. Piglin bags) upon despawn.
* Allows hostile mobs in boats and minecarts to despawn naturally.
* Protects named mobs with name tags from despawning.
* Universal JAR for Fabric, Quilt, NeoForge, and Forge.
